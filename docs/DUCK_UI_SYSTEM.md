# Legacy UI path — NEON SYNDICATE is current

The former Duck Black / Yellow specification has been superseded by [NEON SYNDICATE](../design/NEON_SYNDICATE.md).

This file remains at its original path for compatibility with older documentation links. Current palette values, typography, panel geometry, accessibility requirements, motion rules and screenshot policy are defined in the new visual specification and its machine-readable tokens.

For SAMBU's Tkinter implementation, the active palette is maintained in `sambu_ide/app.py` and `sambu_studio/duck_gui.py`. Vector previews must be described as previews; historical raster captures are not evidence of the current runtime appearance.
