# Observation and chronology primitives

This module turns lessons from accident reports, scientific discoveries and unusual natural events into **reproducible inquiry tools**, not an unverified event catalogue.

- Store observation time separately from the asserted event time.
- Preserve source identifiers and retrieval times; score evidence coverage, never "truth".
- Keep declared causal hypotheses separate from temporal co-occurrence.
- Use robust median/MAD screening as an investigation aid, not an automatic verdict.
- Retain unknowns and conflicting observations; do not silently fill gaps.

The supplied 666-entry register is incomplete in the message (several ranges are placeholders). Its anecdotes are therefore not imported as verified data. Add records only with source references and an explicit evidence state.

Run tests with `python -m unittest discover -s tests -v`.
