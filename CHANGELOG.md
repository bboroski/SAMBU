# Changelog

## 0.2.0 — 2026-11-09

- Added user-defined functions with lexical scope and `return`.
- Added `if` / `else` conditionals and bounded `for ... in` loops.
- Added safe standard helpers: `range`, `sum`, `min`, `max`, and `len`.
- Added directed weighted networks, degree metrics, and strongest-path influence propagation.
- Added bargaining-range overlap, conversion funnels, two-proportion A/B screening, weekly event schedules, attendance capacity, proportional resource allocation, and territory-capture mechanics.
- Added Neo-Modern Diplomat, community-hub, and territory-control examples plus domain documentation.
- Retained SI dimensional checks and the statistical-mechanics library.

## 0.1.0 — 2026-11-09

- Initial SAMBU lexer, parser, evaluator, and command-line runner.
- SI-aware quantities, base dimensions, and dimensional validation.
- Statistical-mechanics helpers for equipartition, Maxwell speeds, Boltzmann weights, partition sums, entropy, and deterministic Maxwell sampling.
- Two runnable examples, a language guide, unit tests, and a GitHub Actions workflow.
