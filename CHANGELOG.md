# Changelog

## Unreleased

- Added explicit read-only contents: read permissions to both GitHub Actions workflows and a standard-library regression test for least-privilege workflow configuration.
- Added an evidence-backed quality state matrix, automatic-improvement policy and versioned rule-catalog baseline; the unavailable original 100-rule source is explicitly marked as incomplete.
- Added an experimental C11 native compiler kernel with typed HIR, SSA MIR, virtual-register LIR, an arena allocator, string interning, IR verifiers, CMake tests and a dedicated CI workflow.
- Added the native compiler architecture contract and staged roadmap; LLVM code generation and the broader systems-language features remain future work.


## Unreleased

- Added five deterministic ecosystem-inspired SAMBU built-ins: imprint_closure, v_vector_stream, countercurrent_sync, biometric_taxonomy_sort and wetland_ecosystem_loop, plus exact-name aliases.
- Added immutable context capture, deterministic worker partition plans, bounded tier-transfer planning, binary trait classification and capacity-based scaling recommendations.

## 0.11.0 — 2026-11-09

- Added sparse voxel grids, affine frames, signed Morton ordering, dirty chunks and per-frame upload planning.
- Added exposed-face surface meshing, Amanatides–Woo ray traversal, sparse octrees and bounded MagicaVoxel VOX v150 interchange.
- Added sparse voxel graphs, CSR Laplacians, Jacobi-preconditioned conjugate gradients and a bounded Spielman–Srivastava-style spectral sparsifier.
- Exposed voxel creation, editing, meshing, octree, raycast, spectral and engine-export operations as native SAMBU built-ins.
- Added starter voxel bridges and compute face-mask kernels for Unity, Unreal Engine, Godot, Bevy 0.20.1 and O3DE, plus generic payload profiles for additional engines.
- Added Unity's three-dispatch GPU face-count, prefix-scan and compact mesh-emission pipeline with indirect indexed-draw arguments.
- Expanded the portable engine profile registry to CRYENGINE, Roblox Studio, Babylon.js, Three.js, PlayCanvas, Cocos Creator, Defold, jMonkeyEngine, Panda3D, Flax, Stride, UNIGINE, OGRE and Source 2 (payload-only profiles).
- Expanded Anatidae models to cover feather barrier, visual profile, avian air-sac phases, gas exchange, bill filtration, salt balance, flight muscle energetics, flocking, imprinting, sleep vigilance and magnetic-heading assumptions.
- Added scientific caveats, reference guides, runnable voxel-world example and regression tests.
- Added a reproducible CPU voxel benchmark harness and a small spectral-solver benchmark mode.
- Added strict non-lossy coordinate/JSON validation and a hard visible-face allocation guard for the CPU mesh reference.

## 0.10.0 — 2026-11-09

- Added postfix percentage literals, modulo arithmetic, and checked percentage helpers.
- Added bounded lazy chunking, deterministic chunk manifests, and conflict-aware reversible text patch sets.
- Added first-class dual-action UI buttons with explicit intent and independent permission checks.
- Added optional Django, Flask and FastAPI adapters for host-authenticated Jiu-Jitsu applications.
- Added evidence-backed portfolio integrity checks with SHA-256, issuer allow-lists, expiry validation and weighted reports.
- Added the sambu-test runner with repeat execution, flaky-test detection and heuristic failure autopsy.
- Added regression tests for the new language, trust, UI and integration contracts.

## 0.9.0 — 2026-11-09

- Introduced 04coq, a declarative in-memory filtering engine with validated rule records, safe field paths and explicit all/any logic.
- Added comparison, membership, text, presence, boolean and collection-length operators, including compatible dimensional-quantity comparisons.
- Added per-rule explanations with stable failure reasons, collection filtering and sequential multi-stage pipelines.
- Added strict resource limits, fail-closed type handling, non-mutation guarantees, regression tests, documentation, an executable example and CI coverage.
- Registered 04coq built-ins and exported the public filtering engine API.
